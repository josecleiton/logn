# Trademark and visual identity

**English** · [Português](TRADEMARKS.pt-BR.md)

The code in this repository is under the **Apache License 2.0**, and you may use,
modify and redistribute it, commercially too. What follows is **not** under that
license.

Section 6 of the Apache 2.0 already says it grants no rights to trade names and
trademarks. This file exists to say, without ambiguity, which ones they are.

## What is reserved

- **The LogN name**, alone or combined, and the `logn.sh` domain.
- **The balloon symbol**, the app icon and the splash art.
- **The visual identity as a trademark**: the combination of palette, typography,
  balloons and strings that makes someone recognize LogN. The code that implements that
  identity (the tokens in `docs/design_system/tokens/` and the app themes) is under the
  Apache 2.0 like any other code. The reservation is a trademark one: you can read, study
  and reuse that code, but a product of yours cannot present itself with the same look.
- **The package identifiers** `sh.logn.LogNiOS` and `sh.logn.app`.

### Brand files

These files are **outside** the Apache 2.0:

- `docs/design_system/brand/`
- `ios/LogNiOS/LogNiOS/Assets.xcassets/AppIcon.appiconset/`
- `ios/LogNiOS/LogNiOS/Assets.xcassets/SplashScreen.imageset/`
- `ios/LogNiOS/LogNiOS/Assets.xcassets/BrandSymbol.imageset/`
- `android/app/src/main/res/drawable/ic_splash_symbol.xml`
- `android/app/src/main/res/mipmap-anydpi/ic_launcher.xml`
- `landing/src/assets/icons/`

They are here because whoever clones the repository needs them for the app to build and
look right while studying or contributing. Being under version control does not license
them.

Third-party marks (store badges, the Google and GitHub logos) are listed in `NOTICE` and
follow their owners' rules.

## What you can do

- Use the code for any purpose, commercial included.
- Run, modify and publish a derivative, **under another name and another visual
  identity**.
- Mention the LogN name to say where the code came from: "based on LogN", "a fork of
  LogN". That is the nominative use the Apache 2.0 itself allows.
- Keep the brand files in your fork while it is a fork, for study or for contributing
  back.

## What you cannot do

- Publish or distribute an app called LogN, or with a name that can be confused with it.
- Use the balloon symbol, the brand files or the visual identity in a product of yours.
- Imply sponsorship, affiliation or endorsement.
- Register the name or the symbol as your own trademark.

## If you want to use it anyway

Ask. The answer may well be yes: contact@logn.sh.

## Track content

The challenges, statements, answer keys and explanations **are not in this repository**.
They are the curriculum, they live separately, and this license does not cover them. A
fork of this code brings up an app that works and has nothing to play until you write
your own content, which is exactly the intent.
